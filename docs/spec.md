# 产品范围与验收标准

## 用户与问题

目标用户有少量代码基础，正在用 Agent 推进真实项目，却缺少项目全局地图和“学到什么程度算过关”的反馈。真实项目对话应继续专注交付，学习在本应用中独立发生。

## 第一版主流程

1. 用户完成五个维度的快速自评。
2. 应用生成技能雷达与推荐起点。
3. 用户进入已解锁关卡，先读“在项目里的位置”和类比，再完成一道选择题。
4. 正确答案获得 XP 和技能成长；错误答案得到解释并可重试。
5. 关卡完成后解锁下一关，刷新页面后进度保留。

## 范围

- 五维技能：项目流程、Git、报错阅读、API/数据流、数据库。
- 六个固定关卡；每关包含目标、项目语境、类比、选择题和解释。
- XP、等级、连续学习、技能值、关卡解锁。
- 可添加个人术语，内置词条可浏览。
- 本地持久化和一键重置。

## 不做

- AI 自动生成关卡、读取项目文件、账号和云同步。
- 排行榜、社交、付费、部署和移动原生应用。
- 用答题分数声称用户具备职业胜任力。

## 可执行验收标准

- 未诊断用户首先看到 5 题诊断，提交后进入主界面。
- 主界面显示等级、XP、连续学习、五维能力和关卡地图。
- 仅首关默认解锁；完成已解锁关卡后，XP 与对应技能增加且下一关解锁。
- 答错不增加 XP，并展示解释；可以再次作答。
- 刷新后诊断和关卡进度仍存在。
- 术语词典可以添加非空、自定义且不重复的词条。
- 重置需要二次确认，并恢复到初始诊断状态。
- localStorage 损坏时应用回退到初始状态而不是白屏。
- 360px 宽度下无横向溢出，核心操作可点击。

## 完成定义

统一验证命令通过；生产构建产物生成；真实浏览器走通“诊断 → 完成首关 → 第二关解锁 → 刷新保留”；错误答案和重置路径被验证；项目文档与实际命令一致。

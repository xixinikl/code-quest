# 冒险成长与收藏规则

## 目标

XP、等级、阶位和伙伴用来让十五章持续有期待感，但只记录训练进度。真实工程能力仍由原始作答、测试、证据任务、延迟复测和真人评审证明。

## 唯一事实源

- 成长计算：`src/careerProfile.ts`
- 章节奖励与解锁物：`src/careerRoadmap.ts`
- 首页、归城和结算反馈：`src/App.tsx`
- 规则测试：`src/careerProfile.test.ts`

## XP 与等级

- 第 1 章首次实战通过奖励 `150 XP`，第 2–15 章首次通过各奖励 `120 XP`。
- 从 `Lv.1` 开始，每 `120 XP` 提升一级；主线最高 `Lv.16`，对应十五章全部留下实战记录。
- 已通关章节复习不重复发 XP，也不重复增加伙伴收藏。
- 旧版本档案按已通关章节补足最低应得 XP，只补不扣；十五章旧档会补到 `1830 XP / Lv.16`。

## 阶位

|   XP | 冒险阶位      |
| ---: | ------------- |
|    0 | 见习开发者    |
|  100 | AI 应用学徒   |
|  360 | 项目修复手    |
|  720 | 证据调查员    |
| 1080 | AI 工程新星   |
| 1320 | Agent 协作师  |
| 1560 | 交付守门人    |
| 1800 | AI 应用工程师 |

阶位沿十五章分布，不能在前五章提前封顶。最终称号是游戏路线身份，不是招聘认证或工作能力结论。

## 反馈顺序

1. 教学完成只进入伙伴会合，不发 XP、不标记通关。
2. 会合页显示本章目标、实战门槛、通过后 XP 与伙伴，并在桌面/手机首屏提供主操作。
3. 只有沙盒测试通过、必填作答完成且成长档案提交成功，才显示等级提升、阶位晋升和伙伴正式归队。
4. 结算继续展示能力印记、Agent 委托和面试表达，但明确它们仍需复测与真人验证。

## 响应式与动效

- 1280×720 和 390×844 的实战前会合页都必须让角色、等级条、三项门槛和主操作在首屏可见。
- HUD、等级条、晋升光效和伙伴卡不得推动按钮或造成横向溢出。
- `prefers-reduced-motion` 下关闭等级条过渡、晋升入场和扫光，不影响信息读取。

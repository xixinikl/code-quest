## 实施切片

### 切片 A：记录真实证据

数据库、API 和最小诊断会话。先证明“原始回答与提示能持久保存”，暂不做复杂 UI。

停止条件：重启服务后记录丢失、schema 不可迁移，或 V1 能力被错误继承。

### 切片 B：真实沙盒任务

加入可复现的“保存成功但刷新丢失”全栈项目、受限验证命令和恢复机制。

停止条件：命令可被用户输入注入、沙盒可访问真实项目、或无法恢复种子状态。

### 切片 C：学习与评分闭环

加入逐步调查、分级提示、操作验证、解释 rubric 和能力证据页。

停止条件：仍可仅靠单选完成、评分理由不可见，或测试通过就被错误判定为理解。

### 切片 D：迁移验证

加入同原理不同表象的复测，并进行真实用户试玩。

停止条件：没有用户试玩却试图宣称“学习有效”，或复测只是换文案不换推理路径。

## 版本控制

本计划不授权提交、推送、PR 或部署。每个切片可以拟定 commit message，但执行需用户另行明确授权。

## G01 确认记录

- 采用本地个人版。
- 使用用户自己的编辑器和终端修改独立沙盒。
- Web 应用不执行 shell，不提供任意命令入口。
- 用户手动运行固定测试；应用仅读取固定路径、结构化的测试报告。
- 使用 SQLite 保存学习记录；localStorage 仅保存可丢失的界面偏好。
- 第一纵向切片不接入 AI 自动评分。

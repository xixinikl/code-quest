# 已知边界与技术债务

- V1 localStorage 进度不转换为可信能力证据；V2 学习记录已迁移到本地 SQLite。
- 当前已有 15 个主线 AI 工程场景和前 15 章的延迟变式复测。第一章复测头像持久化，第二章复测 AI 会议助手，第三章复测客服夜班刷新会话，第四章复测 AI 摘要上游限流，第五章复测 RAG 双 Worker 索引竞争，第六章复测 AI 晨报性能，第七章复测模型密钥轮换，第八章复测引用可验证回答，第九章复测 RAG 检索版本错配，第十章复测 Agent 工具资源越权，第十一章复测过期验收报告，第十二章复测委托边界与回滚，第十三章复测交付证据审查，第十四章复测上线恢复与监控，第十五章复测面试表达边界。
- 第一章延迟复测通过只生成 L3 候选证据；提示使用会如实降级，且在可靠语义审查与真人复测完成前，不能据此声称用户已经完全掌握或能稳定跨场景迁移。
- 自由解释只记录原文与透明 rubric，尚未完成可靠的语义审查。
- 本地学习记录导出和覆盖恢复已经实现；跨设备加密备份与一键清空全部学习记录仍未实现。
- Node 内置 SQLite 在当前运行时仍会显示实验性警告；若接口变化，需要评估固定 Node 版本或改用稳定驱动。
- 无障碍已覆盖语义、键盘焦点和对比度基础项，尚未经过真实读屏用户测试。
- 教学桥工程闭环通过（类型、测试、构建、安全边界不变），但引导式教学的学习效果尚未通过真人验收。
- 第 1–15 章微知识列表和代码导读均已接入四类结构化补课，并记录不惩罚的求助事件；后续仍需根据真人学习卡点校准解释顺序、例子密度和实际帮助程度，不能仅凭功能存在声称学习有效。
- 单屏节奏已完成首页任务简报的第二轮工程优化：当前委托默认展开，迁移复测、后续路线和角色比喻按需展开，并通过桌面/390px 浏览器验收；尚未经过真人长时间学习测试，仍需观察用户是否会在折叠辅助资料与当前任务之间频繁往返。
- 角色、宠物与主场景背景已完成 WebP 优化；教学桥保持按需加载，当前生产主 JS 为 626.52kB，独立教学 chunk 为 310.46kB，延迟复测 Lab 独立 chunk 为 8.16kB。主包仍超过 Vite 的 500kB 建议线，后续需继续拆分首页剧情、路线大厅与各章 Lab。
- 终章职业档案在 390×844 下无横向溢出，但复测卷宗从第二屏开始；仍需在不牺牲剧情和主行动的前提下继续压缩首屏，让下一地图露出更明确的视觉提示。
- 15 章已有不同镜头序列、时长/曲线、地图拓扑、地貌/地标、纹理、节点轮廓和路径节奏；自动化与桌面/390px 浏览器也守住配置完整性、真实分流、首屏节点和响应式边界。但尚未通过真人对照试玩验证“空间差异是否真的降低理解成本”。下一轮应记录玩家能否在不看提示时复述地图分支、回环和汇合，不能把视觉差异直接当成学习效果。
- 教学现场已接入角色台词、背景淡入、人物入场和对白气泡动效，并支持减少动效偏好；尚未通过真人连续试玩验证动效是否帮助记忆地点，或是否增加阅读负担。
- 代码导读已改成逐行巡读，默认不会一次展开全部关键行；仍需真人观察用户是否愿意逐行推进，还是会把“下一行”当成机械点击，并据此调整节奏。
- 教学角色面板现在显示每章真实工作背景，形成“剧情 → 工作 → 证据 → 代码”的顺序；尚未通过真人确认工作背景是否应该更早、更多或更具体。
- 序章倾向已支持从 `baseline-plan` 刷新恢复；历史记录兼容回退已验证，但尚未用全新 attempt 做一次端到端持久化验收。
- 历史档案没有序章选择时已不再显示默认倾向，避免把兼容回退误当成用户行为。
- XP 已贯穿 Lv.1–16，阶位与伙伴解锁也覆盖十五章；旧档补分、重复通关和结算首屏已有自动化/浏览器证据。但奖励是否足够让真人期待下一章仍未验证，后续应观察升级频率、伙伴偏好和结算停留时间，不能用动画数量代替可玩性结论。
- 每幕已加入不惩罚的判断分支，并将选择与主动复述保存为原始记录；尚未通过真人确认玩家是否理解两种证据边界，仍需观察是否会机械点击“沿证据继续追踪”。
- 伙伴图鉴已区分已归队与等待解锁：未收集项保留名字但暗化立绘，只展示章节预告和学习方向；尚未通过真人确认剪影悬念是否提升继续学习意愿，也尚未做真实读屏用户验收。
- TeachingBridge 的按需加载已由生产 manifest 门禁和本次真实浏览器复核确认；当前全通关账号无法直接展示首次教学请求链路，后续需在独立验收数据空间补一次“首页无教学桥请求、进入章节后出现教学桥请求”的网络证据。

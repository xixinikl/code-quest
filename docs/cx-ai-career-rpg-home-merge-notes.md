# `cx/ai-career-rpg-home` 分支交接说明

更新时间：2026-07-16

## 分支定位

当前分支用于把 `code-quest` 从普通学习工具推进成 AI 开发 / 工程实战 RPG 学习路线。`main` 仍是冻结审查基线，不要直接把未审查内容合回 `main`。

### 当前事实快照（2026-07-16）

AI 路线已扩展为 15 章，Java 后端和前端工程路线各 5 章，均有独立章节契约、剧情场景、教学桥、沙盒和成长结算入口。当前分支已推送到 `origin/cx/ai-career-rpg-home`；远端最新提交以 `git ls-remote origin refs/heads/cx/ai-career-rpg-home` 为准。分支尚未合并到 `main`。当前远端默认 HEAD 指向旧 `feat/guided-learning-bridge`，接手和合并前必须显式选择本分支。

最新一轮收口集中在用户反馈最强的“看不懂代码为什么要这么读、谁把东西交给谁、下一步去哪找证据”：第 2 章产品链路不再串到 AI API 安全章；教学桥关键控件已补暗色 RPG 覆盖；第 1 章代码导读新增“当前行证据锚点”，读到 `response.ok` 时明确说明它只能解释前端绿色提示，不能证明数据库已经写入；第 1 章失败测试报告会优先指向数据层写库断点；第 1 章实战后半段已补齐沙盒验收、Agent 委托、交付审查、因果解释和面试迁移的任务卷轴与流程棒；第 2 章失败测试报告能把方向筛选、会话保存、空目标输入分成三类红灯，并先给出「红灯总指挥」排查顺序；第 3 章登录态实战已补齐身份路线、凭证存储、401 反证、刷新复查、Agent 委托、交付审查和面试复盘的剧情向导、任务卷轴、流程接力和交付口令；第 4 章接口审判庭实战已补齐请求体证词、状态码判词、错误体修复、日志串证、Agent 委托、交付审查和面试复盘导演层；第 5 章一致性熔炉实战已补齐 Network 双轨、幂等锤印、唯一约束、事务边界、Agent 委托、交付审查和面试复盘导演层。

这不是最终完成版。当前分支已经形成 15 章路线、暗色 RPG 体验、章节剧情、实战 Lab、成长档案、伙伴收集、面试复盘和本地备份的第一轮完整骨架；第 1、3、4、5 章实战导演层和第 2 章红灯解释已有明显收口。后续还需要真人试玩、逐章教学语言精修、Java/前端深链逐章抽检、全站视觉终审和 PR 合并审查。按产品完整度估计约 70%，可以继续开发，不建议直接合并。

## 当前主要改动

- 首页从单页课程入口改成“序章剧情 → 剧情选择 → 任务简报 → 当前委托”的 RPG 主路径。
- AI 应用开发路线扩展为 15 章，覆盖保存链路、产品 Brief、登录态、接口错误、数据一致性、性能、AI API、幻觉、RAG、Agent 工具、测试验收、Agent 委托、交付审查、上线和面试。
- 每章都接入专属剧情入口、流程接力、名词小抄、关键材料、实战 Lab、Agent 协作、验收和面试复盘。
- 实战 Lab 增加“冒险日志”“当前这一棒”“案件路线牌”“实战接力板”“新手先读卡”“关键行聚焦”“作答支架”和测试失败译文，目标是让新手知道自己在追哪条工作链路。
- 代码导读页增加“读码交接单”，把关键行拆成收到、动作、交出、证明，避免一次甩整段代码。
- 能力护照增加 Agent 委托骨架、验收动作、面试复盘骨架和一键复制按钮，让当前关卡产物能直接带去写 Agent 任务或面试稿。
- 教学桥新增“本章流程回放”，直接从项目地图生成完整路线，避免用户在地图、名词、代码和结案之间切换时忘记上一棒和下一棒。
- 十五章新增独立镜头节奏、地图地貌、关键地标、底图纹理、节点轮廓和路径节奏；地图步骤收紧重复说明，桌面与 390px 首屏能直接露出可操作节点。
- 教学桥新增“本章导师同行”，复用每章剧情角色、地点和台词，让教学页顶部持续有角色陪伴、场景背景和当前学习目标。
- 教学桥新增“导师试炼三印章”，把流程、证据、Agent 委托三项理解检查做成可点亮的轻量闯关反馈。
- 导师试炼三印章点满后会出现完成回响，提示下一步和可带走表达，让轻量闯关反馈有收束感。
- 试炼完成回响支持复制本步收获，方便用户把教学步骤沉淀成复盘材料或 Agent 协作上下文。
- 试炼完成回响和复制文本新增“面试里可以说”一句话，继续把教学步骤压成可复述求职素材。
- 试炼完成回响新增工作能力、Agent 委托、面试素材三格，降低用户从完成反馈里提取收获的成本。
- 试炼完成回响新增即时“能力印记”，增强单步闯关奖励感；当前只作为 UI 反馈，不进入 SQLite 档案。
- 试炼完成回响和能力印记增加轻量解锁动效，并接入 `prefers-reduced-motion`，避免奖励反馈变成视觉负担。
- 导师试炼未点满时会显示还差的印章，点满后收起，避免用户不知道下一步该确认流程、证据还是 Agent 委托。
- 章节卷宗的流程接力已改为读取路线 manifest 中的真实 `flowPayloads`；15 章分别写清草稿 JSON、登录凭证、错误响应、检索命中、测试证据等交接材料，解决“谁把什么给谁”仍然只有抽象系统名的问题。
- 第一章档案馆记录员已从简化 SVG 升级为 `portrait-archive-keeper-v2.webp` 高质量男性导师立绘；首页当前委托、章节卷宗、剧情探索、教学桥和结算页共用同一资产，桌面与 390px 已验证裁切和文字布局。
- 成长系统增加伙伴、宠物、装备、阶位、面试复盘册、作品集 Markdown 出口和本地备份库。
- 通关后的成长档案保留暗色 RPG 风格，并提供“回到路线图，继续冒险”出口，避免复访已通关章节后迷路。

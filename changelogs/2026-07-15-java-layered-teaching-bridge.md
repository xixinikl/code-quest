## Java 第 1 关进入教学桥

Java 后端路线现在可以从职业档案进入第一关“请求为什么要经过三层”。教学过程沿着一封 GET 请求展开，依次经过请求城门、Controller 接待厅、Service 规则熔炉、Repository 档案库和面试答辩台。

这一关会解释 Controller、Service、Repository、DTO、权限检查和持久化等名词，并把代码、Network、日志、数据库查询和失败路径连成同一条证据线。它不会再误显示 AI 第一关“保存成功，但刷新后消失了”。

当前边界：Java 沙盒的修复后测试报告闭环，以及前端岗位路线的真实教学关卡仍在后续任务中。

# 剧情学习进度可恢复

## 用户可感知变化

- 在剧情地点找到线索、写下本幕复述或做出判断后，进度会保存到本地学习记录。
- 刷新页面或重新进入教学桥，会回到上次所在地点，并保留已收录线索和上一幕的学习痕迹。
- 已收录线索仍可点击回看，不会重复增加进度。

## 工程边界

- 未完成剧情保存为 `completed: false` 的教学快照，故事全部完成后才转为已完成记录。
- 恢复数据只接受已知字段，并限制地点索引范围；异常数据会安全回落。
- 不读取、不上传真实项目源码，仍只使用本地学习记录 API。

## 验证

- `npm run typecheck` 通过。
- `npm run test -- --run` 通过。
- `npm run verify` 通过：9 个测试文件、152 项测试、生产构建和按需加载门禁均通过。
- 独立临时数据库浏览器验收通过：找到第一条线索后按 `#chapter-1` 原地址刷新，恢复到同一幕，已收录线索可回看，控制台 0 error。

## 根地址继续

如果用户重新打开根地址，应用会检查第一章当前尝试是否已经开始。已有未完成教学记录会直接进入教学桥，没有记录的新用户仍从序幕开始；全部步骤完成时仍保留完成状态。

## 岗位路线规划

Java 后端和前端工程路线现在各自拥有 4 个完整章节 manifest，岗位选择页可以展示真实学习主题和章节数量。由于真实沙盒和证据读取边界尚未接入，两条路线仍保持未开放状态，不会把规划内容冒充成可玩的教学关卡。

## Java 第一关材料

Java 后端第一关的独立沙盒材料已经加入仓库，主题是“请求为什么要经过三层”。初始测试会明确指出 Controller 绕过 Service 的问题；该关卡暂未在岗位入口开放，等专属场景和浏览器路径完成后再解锁。

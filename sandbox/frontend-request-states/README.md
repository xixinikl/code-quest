# 表单传送厅：请求状态与错误反馈

这是一个独立的前端阅读沙盒。请先看 `frontend/SubmitPanel.jsx`，再根据 Network 记录和测试报告修复它。

## 运行

```bash
npm test
```

应用不会替你执行命令。修复时只修改 `frontend/`，不要修改 `tests/` 或 `evidence/`。

## 事故背景

传送厅只有一盏“成功”灯。用户提交后，页面在请求返回前就宣布成功；遇到 400、503 或超时，也没有告诉用户哪里出了问题、能不能重试。

目标是让一次提交有清楚的状态接力：`idle -> loading -> success/error`。成功必须来自 `response.ok`，失败必须有用户可读的提示，并且按钮不能在请求期间重复提交。

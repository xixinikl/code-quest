# Release Readiness Gate

第 14 章“上线前检查什么”的独立练习沙盒。

这关的剧情是：上线城门已经亮起，交付看起来通过了，但上线守门人不会让你直接点部署。他要你核对：

- 上线计划有没有发布窗口、影响范围、负责人和值守人；
- 生产环境变量、密钥和功能开关是否存在且没有泄露；
- 涉及数据变更时，备份是否可恢复；
- 冒烟测试是否覆盖桌面、390px 移动端和关键路径；
- 上线后监控是否能看到错误率、耗时和业务成功率；
- 回滚条件、回滚步骤和回滚后验证是否写清楚。

## 手动运行

```bash
npm test
```

测试只使用 Node 内置模块，不联网、不访问真实系统。运行后会生成 `test-results.json`，学习应用只读取这份固定报告。

初始状态下测试会失败，这是本章练习入口：用户需要让上线门禁真的拦住不安全上线，而不是把“构建成功”误认为“可以上线”。

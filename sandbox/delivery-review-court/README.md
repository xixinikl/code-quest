# Delivery Review Court

第 13 章“怎么审查交付”的独立练习沙盒。

这关的剧情是：Agent 递上交付说明，说“功能已完成，测试通过”。交付审查官不会只看一句话。他要你核对：

- 交付说明有没有摘要、验证证据、风险和后续；
- Diff 有没有改到任务范围外；
- 测试报告是不是对应当前代码；
- 桌面、移动端、刷新、异常输入等边界有没有覆盖；
- README、任务表、HANDOFF 和 changelog 是否同步；
- 最后应该接收、要求补证，还是明确拒收。

## 手动运行

```bash
npm test
```

测试只使用 Node 内置模块，不联网、不访问真实系统。运行后会生成 `test-results.json`，学习应用只读取这份固定报告。

初始状态下测试会失败，这是本章练习入口：用户需要让交付审查器真的拒绝不可信交付，而不是被“已完成”三个字带走。

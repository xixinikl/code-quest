# Agent 初步交付说明

Network 与 `Server-Timing` 已证明等待主要发生在模型首字阶段，浏览器仅渲染 24 项且没有 Long Task。当前缓存键包含 `requestId`，导致同一团队、同一日期的晨报每次都生成新键。

修复范围应限于晨报性能服务与对应测试：缓存业务身份应由 `teamId + date` 构成，不能跨团队或日期复用；`requestId` 只用于日志关联。修复后需证明第二次相同查询 `HIT`、模型只调用一次，不同团队或日期仍是 `MISS`。

不要删除 `Server-Timing`，不要通过隐藏加载状态掩盖等待，也不要读取真实客服数据。

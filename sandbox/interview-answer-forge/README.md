# Interview Answer Forge

第 15 章“面试怎么讲项目”的独立练习沙盒。

这关的剧情是：终章答辩官把前 14 章徽章摊在桌上，要求你不要再说“我做了一个 AI 项目”，而是讲出能被追问的项目证据。

你要把学习产出锻造成面试回答：

- 素材库要来自真实证据，而不是空泛技术名词；
- STAR 要有背景、任务、行动和结果；
- 故障复盘要能讲出现象、证据、根因、修复和验证；
- 技术取舍要说明候选方案、选择理由、代价和验证；
- 追问答案要能站住，不能靠背模板；
- 最终回答不能夸大真人学习效果，只能说工程证据和个人复盘。

## 手动运行

```bash
npm test
```

测试只使用 Node 内置模块，不联网、不访问真实系统。运行后会生成 `test-results.json`，学习应用只读取这份固定报告。

初始状态下测试会失败，这是本章练习入口：用户需要让答辩稿校验器真的拒绝空话和夸大表达，把项目经历讲成可展示、可解释、可验收的求职素材。

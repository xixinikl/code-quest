# 无障碍交付庭：漂亮的页面是否真的可用

前端工程路线第 4 关的独立交付练习沙盒。

这关的剧情是：交付庭里漂亮的门只有鼠标能打开，审查官要求你核对：

- 关键动作是否使用语义按钮并能用键盘完成；
- 错误提示和状态变化是否能被读屏感知；
- 文字对比度和焦点顺序是否清楚；
- 390px 移动端是否没有横向溢出；
- 自动检查、浏览器路径和旧功能回归是否都有证据。

## 手动运行

```bash
npm test
```

测试只使用 Node 内置模块，不联网、不访问真实系统。运行后会生成 `test-results.json`，学习应用只读取这份固定报告。

初始状态下测试会失败，这是本章练习入口：用户需要让主要流程对键盘、移动端和读屏用户都可完成，而不是把“截图好看”误认为“交付完成”。

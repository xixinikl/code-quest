1. 打开任务列表回归页面。
2. 选择 `status=blocked` 筛选。
3. 确认 Network 里 `GET /api/tasks?status=blocked` 返回 200。
4. 确认 DOM 里只剩阻塞任务。
5. 打开验收报告，核对 `sourceHash` 是否对应当前代码。

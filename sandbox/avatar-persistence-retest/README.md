# 延迟变式复测：头像更新后又变回旧图

这是第一章“保存后刷新消失”的独立变式。它不复用画布业务，也不读取其他项目。

## 业务故障

用户上传新头像后收到 `200 OK`，当前页面立即显示新头像；退出并重新登录后，个人资料接口却返回旧头像。

## 你的目标

不要照抄第一章答案。请重新沿“上传面板 → 资料接口 → 数据访问层 → SQLite → 重新登录读取”建立证据链，定位读写是否落在同一个事实源。
